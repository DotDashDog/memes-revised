# Project Documentation

This folder is the project record: intent, design decisions, and current state. Code,
datasets, and scratch files outside `docs/` implement what is recorded here. The layout and
working agreements are in [`/AGENTS.md`](../AGENTS.md).

## Conventions

- **File naming.** ADRs: `NNNN-short-slug.md` (zero-padded, sequential). Work packages: `WP-NN-short-slug.md`.
- **Cross-references.** Relative paths (e.g., `decisions/0003-reddit-only.md`).
- **Code citations.** `path:line-line` form, so an IDE can jump.
- **Status fields.** Every ADR and work package has a `Status:` line in its header; keep it current.
- **Section numbers in `01-scientific-rigor.md`** are cited elsewhere and have intentional gaps. Do not renumber.
